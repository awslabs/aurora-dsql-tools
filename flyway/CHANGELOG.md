# [Aurora DSQL Flyway Support v1.0.0 (flyway/v1.0.0)](https://github.com/awslabs/aurora-dsql-tools/releases/tag/flyway/v1.0.0) - 2026-01-31

Initial release of Flyway database plugin for Amazon Aurora DSQL.

### Features
- Recognizes `jdbc:aws-dsql:` JDBC URLs
- Bypasses `SET ROLE` commands (DSQL uses IAM authentication)
- Handles one-DDL-per-transaction requirement
- Bypasses advisory locks (DSQL uses optimistic concurrency control)
- Properly drops views before tables during `flyway clean`

### Installation

```xml
<dependency>
    <groupId>software.amazon.dsql</groupId>
    <artifactId>aurora-dsql-flyway-support</artifactId>
    <version>1.0.0</version>
</dependency>
```

# [Aurora DSQL Flyway Support v1.0.1 (flyway/v1.0.1)](https://github.com/awslabs/aurora-dsql-tools/releases/tag/flyway/v1.0.1) - 2026-01-28

## Aurora DSQL Flyway Support v1.0.1

First release from the [aurora-dsql-tools](https://github.com/awslabs/aurora-dsql-tools) monorepo.

### Installation

**Maven:**
```xml
<dependency>
    <groupId>software.amazon.dsql</groupId>
    <artifactId>aurora-dsql-flyway-support</artifactId>
    <version>1.0.1</version>
</dependency>
```

**Gradle:**
```groovy
implementation 'software.amazon.dsql:aurora-dsql-flyway-support:1.0.1'
```

### What's Included

- Flyway database plugin for Amazon Aurora DSQL
- Automatic transaction splitting for DDL statements
- IAM authentication support via Aurora DSQL JDBC Connector
- Compatible with Flyway 11.3+

See the [README](https://github.com/awslabs/aurora-dsql-tools/tree/main/flyway) for full documentation.
