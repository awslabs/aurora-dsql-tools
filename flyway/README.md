# Aurora DSQL Flyway Support

This adapter is deprecated.

Use the official
[`org.flywaydb:flyway-database-dsql`](https://github.com/flyway/flyway-community-db-support/tree/main/flyway-database-dsql)
community module.

Existing releases of
`software.amazon.dsql:aurora-dsql-flyway-support` remain available from
[Maven Central](https://central.sonatype.com/artifact/software.amazon.dsql/aurora-dsql-flyway-support).
Existing users should migrate to the official module. Do not load both
modules in the same Flyway runtime.
